# Afrad Enterprise — Website

Static company site (home + contact). No build step.

- `index.html` — landing page
- `contact.html` — contact page + form
- `styles.css`, `script.js`, `assets/` (logo, favicon)

Change the contact email in `script.js` → `CONTACT_EMAIL`.

Deploy: GitHub Pages → Settings → Pages → Branch `main` / root.
Custom domain: add `CNAME` file containing `afradenterprise.com`.
